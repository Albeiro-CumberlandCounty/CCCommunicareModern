# Referral Form Review

## Source reviewed

CommuniCare Referral Form, revised 5.23.23, supplied by CommuniCare during M3 content validation.

The source document itself is **not** being committed to this public repository because the copy supplied for review contains populated personal information.

## Public-site decision

Do not recreate this referral workflow as a web form on GitHub Pages.

The form collects or requests information that can include:

- name and date of birth
- race, gender, age, school, and education information
- Social Security number
- home address and parent/guardian information
- phone and employment information
- military status
- referral source and legal/court information
- court history and case identifiers
- behavioral, mental-health, trauma, medication, and substance-use information
- insurance, Medicaid, provider, and income information
- signatures and legally responsible person information

This is outside the approved static public-site architecture.

## Important finding

The copy supplied for review is not a clean blank template. It contains populated example/client/referral information in portions of the first two pages.

Because the repository is public, this file must not be committed as-is.

## Recommended website approach

The public Get Help / Referrals page should provide:

- referrals@cccommunicare.org
- 910-829-9017
- plain-language instructions for how to start a referral
- an accessible blank referral form only after CommuniCare provides/approves a clean version
- approved instructions for returning the completed form

Do not state that ordinary email is an approved method for transmitting completed forms containing sensitive information until CommuniCare/ITS confirms that workflow is acceptable.

If secure electronic submission is needed later, treat it as a separate architecture/security requirement rather than implementing it directly in GitHub Pages.

## Content/version review needed before publication

The form is dated 5.23.23 and its service checklist should be reconciled against Sarah Hallock's current program decisions before any blank form is published.

A new clean version should:

- remove any populated personal/referral information
- reflect the current program/service list
- remove deleted or obsolete program names
- add any new programs/services that belong on the referral form
- use current contact information
- be reviewed for accessibility
- be exported to an accessible public format, preferably an accessible tagged PDF or another approved accessible document format
- include only approved submission instructions
